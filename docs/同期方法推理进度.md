## 已运行方法详情

### 1. 4RC

- **代码版本**：`a08ca0a5394c7c5f6a2a3423223cb98f85f84e6a`
- **发布权重**：`Luo-Yihang/4RC`，revision `3634b324abb16634a527987c8efa212e392a1449`
- **正式 Run**：`R-20260809161132-d5c39e`
- **协议**：147 个原生 MOVi-F validation clips，连续 21 帧，`clip_start=0`，全部 21 个 source，`pixel_stride=16`，WorldBridge validity `A`，遮挡但几何有效的点保留。
- **对齐**：每个 clip 用全部有效点拟合一个 closed-form Sim(3)，并将同一个变换用于所有指标子集。

| 指标 | pooled EPE（m） |
|---|---:|
| Pointmap (`s=t`) | 0.3684 |
| First-frame tracking (`s=0`) | 0.4891 |
| Arbitrary all `(s,t)` | **0.4010** |
| Arbitrary visible | 0.3455 |
| Arbitrary occluded-valid | 0.6379 |
| Late-appearing | 0.7390 |

未对齐 arbitrary EPE 为 **15.0823 m**。因此 4RC 的 `0.4010 m` 是 **GT-fitted Sim(3) aligned reference**，不能直接与 WorldBridge 固定坐标系的 raw EPE 横向比较。Late-appearing 还存在明显长尾，不能只依据 pooled 值判断稳定性。

### 2. St4RTrack

- **发布权重**：`St4RTrack_seq_reweight5`
- **正式 Runs**：`R-20260809082152-35ef45`（batch 2）和 `R-20260809082413-edf253`（batch 8，独立复现）
- **协议**：固定 32 个 MOVi-F validation clips，连续 21 帧，全部 441 个 `(source,target)`，官方 512×512 no-crop 预处理。
- **结果**：batch 8 strict raw off-diagonal EPE **12.7843477 m**；visible/occluded-valid 分别为 **12.4844/14.1800 m**。每 clip 单一正尺度诊断为 **7.9589565 m**。
- **复现性**：两次运行的 raw 和尺度对齐 EPE 差异均小于 `2.5e-5 m`。

这些数值表明零样本 metric transfer 不具竞争力，但当前尺度诊断不能旋转或平移。H024 正在补做每 clip 单一 proper Sim(3) 的 oracle 诊断；完成前不得把 St4RTrack 与 4RC 的 aligned EPE 当作同协议结果。

### 3. Any4D

- **发布权重**：`any4d_4v_combined.pth`
- **正式 Run**：`R-20260809163153-d22f36`
- **协议**：147 个 MOVi-F validation clips，连续 21 帧，仅 `source=0`，`pixel_stride=16`，RGB-only，原生 518×518 square 输入；输出下采样到 128×128 网格评测。
- **对齐**：只移除模型预测的第一相机 pose 并做声明的坐标基转换；**没有**依据 GT 拟合 scale、SE(3) 或 Sim(3)。

| 指标 | EPE（m） |
|---|---:|
| Pointmap | 8.8519 |
| First-frame tracking | 8.3846 |
| First-frame visible | 8.2126 |

工程推理成功，峰值显存约 **14.27 GiB**；但 source-0 质量已明显低于当时 WorldBridge 阈值，因此停止 all-source 穷举。该结果只能记为 **source-0 zero-shot reference**，不能宣称已完成 arbitrary-source 评价。

## 可比性约束

1. **Raw 与 aligned 指标分栏报告**：GT-fitted Sim(3) 只能作为显式标注的 oracle 对齐诊断。
2. **一个 clip 只允许一个全局变换**：不得按 pair、可见性或 late-appearing 子集分别拟合。
3. **完整 arbitrary-source 必须覆盖全部 source**：仅 `source=0` 的 Any4D 结果不能填入 arbitrary all-`(s,t)` 栏。
4. **匹配数据人口**：比较时需同时匹配 clip/split、帧数、source、像素采样、validity、遮挡处理和输入裁剪；仅匹配指标名称不够。
5. **论文数字与本地推理解耦**：未在本页登记 Run 的方法一律视为“未本地推理”。
