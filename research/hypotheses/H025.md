# H025 — Matched Wan 14B LoRA training on GPUs 0/1

## Hypothesis

The running H023 two-rank 256×256, K=16, microbatch-2, accumulation-2,
approximately 200M-readout trajectory can replace full Wan2.1-1.3B fine-tuning
with rank-16 LoRA on Wan2.1-14B while preserving every data, prompt, sampling,
decoder, optimization, seed, and 100,000-update setting. Because the highest
readout is block 29, only the exact Wan 14B executed prefix `0..29` needs to be
loaded; frozen blocks `30..39` are outside the forward and checkpoint.

The route is falsified at the engineering gate if two real BF16 FSDP FULL_SHARD
ranks on physical GPUs 0/1 cannot complete two finite optimizer updates under
the existing 80 GiB cards, if gradients do not update the injected LoRA path,
or if the matched data/readout contract changes. Passing the gate establishes
capacity only; quality relative to the running 1.3B arm requires the long run
and matched evaluation.

## Fixed protocol

- Physical GPUs: `0,1`; world size 2.
- Wan: `/dataset/nas0/yejun/Wan2.1-T2V-14B`, native sharded checkpoint,
  selectively loaded through block 29.
- LoRA: rank/alpha `16/16`, dropout 0, attention Q/K/V/O and both FFN linears.
- Readout layers and initial weights: `[13,14,15,29]`, `0.3/0.3/0.3/0.1`.
- Resolution/targets: 256×256, 21 frames, K=16.
- Batch: microbatch 2/rank, accumulation 2, eight clips and 128 pairs/update.
- Readout, datasets, prompts, learning rates, warmup, cosine horizon, seed, and
  checkpoint cadence match the running GPU-4/5 configuration.
- The Wan 14B VAE file is byte-identical to the 1.3B VAE
  (`sha256=38071ab59bd94681c686fa51d75a1968f64e470262043be31f7a094e442fd981`),
  so the deterministic 256 latent cache contract is unchanged.

## Evidence

Implementation reuses the exact active H023 training/cache stack, adds native
Wan architecture discovery and selective sharded loading previously exercised
by H021, and adds the rank-16 LoRA injection route previously capacity-tested
by H022. The widened four-layer 14B hidden projections produce 200,955,397
non-Wan parameters; this is the architecture-implied 7,368,704 increase over
the 1.3B readout, while all configured readout dimensions remain unchanged.
The pre-launch suite passes 86 tests, including LoRA zero-initial equivalence,
frozen-base gradient behavior, native 14B architecture discovery, checkpoint
key conversion, and the current H023 data/cache tests. The real two-GPU gate is
pending.
