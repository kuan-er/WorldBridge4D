# H013 — Default full-target source supervision and DiT fine-tuning

## Goal

Make the canonical dense4d training profiles supervise a complete 21-target trajectory from one sampled source on every update and fine-tune the Wan DiT, geometry adapter, and dense decoder together. This is a requested default-policy change, not a retrospective reinterpretation of H007.

## Implementation contract

- Add `pair_sampling: source_all_targets`; require `num_query_pairs == clip_length`.
- On every update and for every clip in the batch, sample one source `s` and emit `(s,0)..(s,20)` in target order.
- Set the four canonical profiles to 21 queries and `trainable_mode: full`; the tiny fixed-overfit profile uses source 0 with all targets explicitly listed.
- Keep the four canonical dense4d profiles as the only shipped dense4d training configs; historical H004–H007 experiment settings remain recoverable from Git and research records.
- Unit-test that the sampler has one source and exhaustive ordered targets. A real full-gradient smoke must continue to require gradients in actual Wan, adapter, and decoder parameters before any quality claim.
