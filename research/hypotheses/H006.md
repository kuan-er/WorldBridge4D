# H006 — Motion-slot necessity and capacity

## Hypothesis

The H005 triad's persistent per-frame `Z_motion` slots provide non-local motion information that cannot be fully replaced by its frame-aligned dense planes and source-local query skip. Under the frozen-Wan geometry-adapter protocol, a retrained eight-slot model should therefore reduce held-out arbitrary-source tracking EPE relative to a matched dense-only (`M=0`) model. The slots are not considered necessary if the two-seed mean gain is below 1%, changes sign across seeds, or is confined to the noisy late-appearing subset.

The primary comparison reuses the already trained H005 triad `[13,14,15]`, `M=8` checkpoints and trains matched `M=0` controls with identical 32 training clips, 1,536 updates, pair sampler, decoder seed, and geometry seeds 2026/2027. Evaluation is restricted to the existing train-split candidate holdout indices 80–111 at `pixel_stride=16`; the final 147-clip validation split is not used for architecture selection. Primary metrics are arbitrary all-`(s,t)` and tracking EPE. Pointmap, occluded-valid, temporal-gap, first-frame, and late-appearing EPE are secondary diagnostics.

Two complementary tests distinguish actual slot use from optimization/capacity effects: (1) zero-shot removal or zeroing of the learned slot memory in each trained `M=8` checkpoint, and (2) slot diversity/effective-rank diagnostics across held-out clips. If slots help but are redundant, a smaller matched slot count is an improvement opportunity; if they collapse or weakly affect predictions, explicit pair-conditioned or temporal slot refinement is preferable to increasing slot count. Any follow-up variant is selected only on the same development holdout and must beat `M=8` on both primary metrics without a material occluded/late-appearing regression.

## Evidence

Task `T-20260809095937-66b0d0` evaluated all variants on train-split holdout indices `80–111`; the final 147-clip validation split was not used. Training used triad blocks `[13,14,15]`, 32 train clips, 1,536 updates, geometry-adapter optimization, seeds 2026/2027, and the original H005 decoder seed. Evaluation used exhaustive `(s,t)` pairs and `pixel_stride=16`. The final aggregation is Run `R-20260809104655-139b16` and artifact `/tmp/worldbridge_h006_slots_aggregate.json`.

### Necessity: retrained dense-only control

The true `M=0` implementation retains the source-local dense query path but constructs no slot embeddings, slot attention, slot normalization, or slot memory. Its training Runs were `R-20260809100423-17a923` and `R-20260809100427-95f218`; holdout Runs were `R-20260809101323-3fb6d8` and `R-20260809101310-2a4c3a`.

Two-seed mean EPE in metres:

| Metric | Learned `M=8` | Retrained `M=0` | `M=0` change |
|---|---:|---:|---:|
| Pointmap | **3.9453** | 4.3067 | +9.2% |
| First-frame | **4.1689** | 4.3007 | +3.2% |
| Arbitrary `(s,t)` | **3.9904** | 4.3541 | +9.1% |
| Arbitrary occluded | **4.9183** | 5.4069 | +9.9% |
| Late appearing | **3.8928** | 4.1634 | +7.0% |
| Tracking | **3.9926** | 4.3564 | +9.1% |

Equivalently, adding the learned slots lowers arbitrary EPE by `8.35%` relative to the retrained dense-only control. The primary arbitrary/tracking gain has the same sign on both seeds, satisfying the predeclared necessity criterion. The slot model has 4,396,228 trainable parameters versus 4,326,212 for dense-only, a 70,016-parameter increase (`1.62%`).

### Causal use and representation diagnostics

Zero-shot perturbations of the already trained `M=8` checkpoints separately preserved the slot-token count while replacing values with zero, or removed all slot tokens. Relative to learned slots, two-seed arbitrary EPE degraded by `15.0%` when values were zeroed and `16.4%` when tokens were dropped; occluded EPE degraded by `13.1%` and `13.9%`. The zero Runs were `R-20260809101411-fb0100`/`R-20260809101421-f70d60`; drop Runs were `R-20260809101416-156f40`/`R-20260809101426-f648c9`. Thus the result is not explained only by extra token count or attention normalization: learned clip-dependent slot content is causally used.

However, the eight-slot representation is highly redundant. Across holdout clips, mean within-frame off-diagonal slot cosine similarity was `0.99986` and `0.99991` for seeds 2026/2027. The adjacent-frame same-slot versus other-slot cosine margin was only `1.36e-4` and `8.07e-5`, while cross-clip variation accounted for only `19.0%` and `17.4%` of motion-slot RMS. Diagnostic Runs were `R-20260809101331-dbe9e0` and `R-20260809101336-34c904`. The slots act as useful near-duplicate global summaries, but the intended persistent slot identity is not strongly realized.

### Improvement probes

A pair-conditioned probe pooled slots at source and target frames and injected `[mean_s, mean_t, mean_t-mean_s]` into every pair query. Shared baseline decoder parameters retained exactly the same seeded initialization. Direct initialization (`R-20260809101945-71837c`, `R-20260809101957-dc1517`; evaluation `R-20260809102926-0e24c8`, `R-20260809103003-672503`) improved two-seed pointmap/arbitrary/occluded EPE by `9.4%/9.4%/8.1%`, demonstrating that the slot summaries contain additional easily accessible geometry. It simultaneously worsened late-appearing EPE by `47.2%`.

A safer residual version zero-initialized the final pair projection, making the initial model function exactly identical to the baseline (`R-20260809103421-0153eb`, `R-20260809103432-34306d`; evaluation `R-20260809104415-190bdb`, `R-20260809104354-b001f8`). It improved pointmap/arbitrary/occluded EPE by `6.1%/6.4%/7.1%`, but worsened late-appearing EPE by `87.1%`. Both pair-conditioned variants add 165,120 trainable parameters (`3.76%`). They are rejected because they violate the predeclared no-material-late-regression criterion.

## Conclusion

Motion slots are necessary for the current H005 triad at this budget: retraining without them and zero-shot removal both produce large, reproducible held-out degradation. The current eight-slot mechanism nevertheless has substantial improvement space because slot identities nearly collapse. A global pooled pair shortcut can unlock 6–9% ordinary-geometry gains, but its severe and reproducible late-appearing regression shows that future work must use source-valid/appearance-aware gating or preserve slot-specific residuals rather than broadcasting a global mean motion shortcut. The original learned `M=8` H005 design remains the default; neither pair-conditioned probe is promoted, and no H006 selection was performed on final validation.
