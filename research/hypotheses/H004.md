# H004 — Dense-query 4D latent from feed-forward Wan

## Question

Can a minimally modified pretrained Wan2.1-1.3B map a clean MOVi-F RGB video latent through one DiT forward at rectified-flow time zero into a reusable implicit `Z4D`, such that a lightweight dense `(source,target)` cross-attention decoder predicts a complete source-grid XYZ map for arbitrary source times?

## Prediction

With the Wan VAE frozen and no direct `Z4D` supervision, validity-masked XYZ supervision over balanced diagonal and off-diagonal pairs should (1) strongly overfit fixed pairs from 1–4 clips, (2) decrease for randomly sampled forward, backward, long-gap, and `source>0` queries on the same clips, and (3) complete bounded held-out evaluation with finite pointmap, visible tracking, and occluded-valid tracking metrics. The same `Z4D` must serve every pair and retain Wan's native `[16,6,16,16]` topology.

## Falsification / gates

Do not train until native MOVi-F geometry, Wan's clean-latent shape, timestep-zero convention, and raw velocity sign pass direct audits. The feasibility claim fails if fixed-pair loss does not materially decrease, arbitrary-source loss is flat, gradients do not reach Wan DiT parameters, or the decoder cannot distinguish spatial positions using 2D RoPE.

## Fixed v1 scope

- RGB -> frozen Wan VAE mean latent -> one full Wan DiT forward at flow time zero -> verified negative raw velocity -> `Z4D`.
- Full flattened `Z4D` memory; independent learned source/target embeddings; dense 16x16 query grid; 1–2 cross-attention/FFN blocks with spatial-only 2D RoPE; bilinear 2D upsampler to 128x128 XYZ.
- No GT latent, latent loss, camera input, visibility head, source RGB patch, query self-attention, temporal RoPE, delta-time embedding, or iterative diffusion.

## Evidence

Task `T-20260807120421-6da6ff` completed the staged gates and a bounded feasibility run.

- Dataset audit: `R-20260807120649-ce3667`; geometry validation: `R-20260807121556-0d3599`. On two real clips, pixel round-trip max was `1.08e-13` px, diagonal `X_s^s=P_s` error was exactly zero, rigid transform max was `5.02e-7` m, static background max `2.06e-6` m, and both visible and occluded-valid populations were present.
- Train-only coordinate statistics: `R-20260807122258-659248`, all 5,737 train clips / 1,973,886,172 valid pointmap XYZ values. `mu=[-0.004756,1.984044,-13.474529]`, `sigma=[4.819901,5.335501,11.895373]`.
- Wan audit: `R-20260807121940-5cafa5`; native empty condition: `R-20260807121652-27b9ac`. Clean VAE mean, exact tau/timestep zero, `v=epsilon-x0`, `Z4D=-v`, shape equality, and actual DiT gradient all passed. Decoder smoke `R-20260807122056-d99561` and 21 unit tests `R-20260807122126-c56ffb` passed.
- Fixed-pair tiny overfit: successful retry `R-20260807123135-3e0f39`. Failed plumbing attempts are retained: `R-20260807122910-ddca60` caught an unspecified CUDA device index and `R-20260807122942-7814b1` caught PyTorch weights-only NumPy metadata; both were fixed before the successful run. On one clip and four fixed pairs, normalized XYZ loss fell `2.9519 -> 2.1182` (ratio `0.7176`), all-pair EPE `15.449 -> 10.828` m, and full Wan had `1,421,684,163` trainable parameters; real checkpoint save/load passed.
- Arbitrary-query tiny overfit: `R-20260807123252-527d39`. With random balanced queries, evaluation loss fell `3.0702 -> 1.7698` (ratio `0.5765`) and EPE `15.916 -> 8.022` m. Both `source=0` and `source>0`, diagonal, forward and backward queries were sampled; final source-zero/source-positive EPEs were `8.340/7.886` m. This supports reusable query conditioning on the same clip.
- Bounded train: `R-20260807123356-35e147` (8 train clips, 32 updates, checkpoint save/load). Bounded validation: `R-20260807123513-8d40a0` (2 validation clips, exhaustive 441 `(s,t)` pairs per clip). Pointmap EPE/XYZ-MAE was `11.457/5.486` m. Off-diagonal tracking EPE/XYZ-MAE was `11.419/5.461` m; visible EPE `11.980` m; occluded-valid EPE `8.670` m; source-zero EPE `10.694` m; source>0 EPE `11.455` m. EPE versus temporal gap 1..20 ranged only `11.436..11.216` m under this deliberately tiny cross-clip budget.

The engineering feasibility hypothesis is supported: all gates passed, fixed and arbitrary-source tiny losses decreased, and one Z4D answered diagonal and arbitrary source-target queries. Bounded quality is not a generalization claim; its dominant limitation is the tiny 32-update Wan/DiT optimization budget. No claim is made that the current model is accurate on full MOVi-F.
