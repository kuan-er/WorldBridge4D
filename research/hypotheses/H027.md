# H027 — Pre-attention source-RGB spatial query residual

## Hypothesis

The selected H023 step-100k decoder can use source appearance more effectively
if its aligned 32×32 RGB-pyramid feature is projected into each spatial query
*before* the five Z4D cross-attention blocks. A zero-initialized unconditional
additive projection should preserve the exact migration endpoint, then learn to
alter memory retrieval without a sigmoid gate. With Wan and geometry frozen,
10,000 decoder-only updates should produce a robust decrease in per-dataset and
7/6/7 mixture-weighted training loss.

The engineering route is falsified if the new branch changes the initial
step-100k output, fails audited model/AdamW migration, exposes any backbone
parameter as trainable, or cannot complete finite two-rank B2/A2/K19 updates.
The optimization prediction is not supported if the first/last matched windows
remain flat or regress. Training loss alone is a screen; any promotion still
requires a matched continued-bilinear control and held-out evaluation.

## Fixed protocol

- Source checkpoint: H023 global step 100,000, SHA-256
  `3181a255d48687f1634fe62372355815a61f9aba5fef40bca50572459145d0f2`.
- Hardware policy: physical GPUs `0,1` only, world size 2. GPU 3 is prohibited
  by the repository GPU allowlist; runs wait for GPU 0 rather than falling back.
- B2/A2/K19, BF16 FSDP FULL_SHARD, seed `20260812`.
- Wan DiT and geometry adapter frozen; every decoder parameter trainable.
- New branch: `RGB32 [B,128,32,32] -> GroupNorm(affine=False) -> SiLU ->`
  zero-init `Conv2d(128,1536,1,bias=False)`, then expand over K and add to the
  spatial query before cross-attention. It adds exactly 196,608 parameters and
  has no alpha or spatial sigmoid gate.
- Existing decoder and source-RGB AdamW moments plus rank-local RNG are restored;
  the one new projection tensor gets fresh lazy AdamW state in the source-RGB
  optimizer group. Mature dense-decoder LR retains the 0.1× cap; source-RGB
  groups retain the production 10× multiplier.
- Phase 1 trains step 100,000 -> 102,000 and publishes W&B metrics plus a full
  checkpoint. Inspect loss, EPE, gradients, memory, and branch behavior before
  exact-resuming phase 2 through step 110,000.
- W&B project/group: `worldbridge4d` /
  `h027-pre-attention-rgb-query-step110000`.
