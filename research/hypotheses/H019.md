## Evidence

The initial `requirements.txt` listed only NumPy, PyYAML, Torch, TensorFlow, Matplotlib, pytest, Diffusers, Safetensors and Transformers. Static import auditing found four direct omissions needed by the merged pipeline: `wandb` (formal training curves), `scikit-learn` (H005 analysis scripts), `nvidia-ml-py` (GPU telemetry in source-centric training), and `jsonschema` (dataset manifest validation). The native Wan empty-condition helper also requires `sentencepiece` and `ftfy`; `accelerate` is included for the Diffusers/Transformers loading stack. The TensorFlow dependency is changed to `tensorflow-cpu` because this project uses it only for TFRecord parsing and should not let TensorFlow contend for training GPU memory.

The validated environment gate `scripts/check_environment.py --require-cuda` passed on Python 3.10.13 with Torch `2.10.0+cu126`, CUDA `12.6`, an NVIDIA A800 80 GiB GPU, TensorFlow CPU `2.15.1`, Diffusers `0.36.0`, W&B `0.24.0`, and all project imports. The manifest JSON Schema check and the existing 41-test suite also pass. Exact direct-package versions are recorded in `constraints-known-good-cu126.txt`; CUDA-specific PyTorch installation remains deliberately documented separately because another host may require a different wheel.
