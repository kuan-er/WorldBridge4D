# H020 — PointOdyssey three-GPU DDP transfer (100k update budget)

## Question

Can the approximately 100M geometry/readout Dense4D profile be trained for 100,000 synchronized optimizer updates on PointOdyssey immediately after the existing GPU 2/4/6 jobs release all three cards?

## Prediction

The native identity-preserving PointOdyssey tracks provide valid sparse source-grid XYZ trajectories, including occluded-valid supervision. Three-rank DDP with one physical clip per rank (global batch 3), full Wan/adapter/decoder fine-tuning and deterministic frozen-Wan latent caching should produce finite loss curves while keeping the H013 100M architecture within each 80 GiB card.

## Fixed protocol

- Start immediately on physical GPU 4. As physical GPUs 2 and 6 finish their owner jobs, checkpoint at the next optimizer boundary and restart with two, then three NCCL ranks. Native DDP cannot add ranks in place; model, AdamW state and global step are preserved across each membership restart.
- `/dataset/PointOdyssey`, fixed non-overlapping 21-frame clips, center-cropped 540x540 then resized to 128x128.
- Source-frame sparse XYZ from PointOdyssey identity tracks; `valids`, never `visibs`, masks the training loss.
- H013 capacity architecture: `geometry_dim=512`, `query_dim=1024`, five cross-attention blocks, hidden triad `[13,14,15]`, eight motion slots, full Wan fine-tuning and BF16 checkpointing.
- Conservative largest reference physical batch: one clip per GPU, global batch three, no accumulation. This follows `dense4d_capacity_100m.yaml`; the first formal update remains the binding 80 GiB capacity check.
- Exactly 100,000 synchronized optimizer updates, seed 2029, 256-step warmup, periodic exact model/optimizer checkpoints every 5,000 updates.
- Rank zero uploads explicit-global-step loss, EPE, throughput and memory curves to W&B project `worldbridge4d`.
- The progressive handoff snapshots the current high-memory processes on GPUs 2/6 and checks once per 60 seconds. A card joins only after its owner PID disappears and it has at least 70,000 MiB free; GPU 4 is claimed immediately.
