# H001 — Geometry-supervised 4D latent baseline

## Question
Can deterministic 4D latents built from MOVi-F geometry and rigid trajectories decode source-conditioned 3D queries, and does retaining a latent for every source pixel (Full) improve over a first-frame trajectory anchor plus per-frame reconstruction (Compact)?

## Prediction
Full should be stronger on arbitrary-source tracking, especially points belonging to objects that first appear after frame 1. Compact should use the same latent shape and decoder while retaining useful reconstruction and first-frame tracking performance with less trajectory content.

## Planned comparison
- Dataset: read-only `/dataset/MOVi-F`, using the discovered native fields and coordinate conventions.
- Inputs: pointmaps, validity, segmentation, camera metadata and derived rigid trajectories; RGB is diagnostic only.
- Models: Compact and Full as specified by the project request, deterministic and matched in trajectory/context capacity.
- Primary metrics: 3D endpoint error, per-coordinate MAE, target-camera reprojection error, split by reconstruction/tracking and visible/occluded points.
- Controls: fixed seeds/configuration, train-only coordinate statistics, blockwise query/trajectory processing, tiny-overfit and bounded baseline runs.

## Falsification / stopping criteria
The hypothesis is not supported if Full does not improve arbitrary-source or late-appearing-object tracking in the bounded comparison, or if either model cannot pass geometry round-trip and tiny-overfit checks.

## Reproducibility
All commands, configs, seeds, git revisions, hardware, and PRL Run IDs will be recorded in `research/STATE.yaml`, `research/DECISIONS.md`, and run metadata. No dataset files, weights, caches, or generated outputs are committed.

## First implementation result
Geometry, shape, save/restore and unit checks passed. Tiny fixed-query overfit passed for Compact (30 steps, loss ratio 0.345) and Full (30 steps, ratio 0.431). In the bounded validation comparison (4 train clips, 20 steps), Compact reached reconstruction / first-frame endpoint errors 7.04 / 6.37, while Full reached 11.29 / 10.17; Full arbitrary-source evaluation is implemented and ran over all source/target time pairs on a deterministic spatial grid, but did not improve under this deliberately small budget. H001 is therefore not supported by the first bounded quality comparison, while the engineering feasibility prediction is supported.

## Three-seed reliability result
The full MOVi-F train split was used for three epochs per seed (`2026/2027/2028`, 17,211 global clip updates), followed by all 147 validation clips at pixel stride 16. Mean and sample standard deviation were aggregated across seeds.

| Endpoint error | Compact | Full |
|---|---:|---:|
| Reconstruction | 1.2043 ± 0.0273 | **1.1603 ± 0.0313** |
| First-frame all | **1.0114 ± 0.0405** | 1.0771 ± 0.0680 |
| First-frame visible | **0.8520 ± 0.0361** | 0.8994 ± 0.0634 |
| First-frame occluded | **1.5415 ± 0.0571** | 1.6682 ± 0.0840 |

Full-only endpoint errors were `1.2348 ± 0.0335` for exhaustive arbitrary `(s,t)` queries (`1.0576 ± 0.0274` visible, `1.9912 ± 0.0604` occluded) and `3.1070 ± 0.1168` for late-appearing objects (`2.5626 ± 0.1084` visible, `3.8113 ± 0.1279` occluded). Random arbitrary-source evaluation agreed with the exhaustive result (`1.2351 ± 0.0364` overall).

Full improved common-task reconstruction EPE by 3.7%, but worsened first-frame EPE by 6.5% overall, 5.6% on visible points, and 8.2% on occluded points. It successfully adds arbitrary-source and late-appearing query capability, but Compact has no corresponding arbitrary-source output, so the predicted quality improvement on those groups is not established by a direct matched comparison. Late-appearing occluded error remains especially high. Therefore H001's engineering-feasibility component is supported, while the stronger claim that Full is a quality improvement over Compact is not supported by this matrix.
